# 북수원자이렉스비아 보안대원 근무 매뉴얼

신입 보안대원이 근무 중 휴대폰으로 **지금 할 일, 처리 방법, 보고 대상**을 바로 확인하는 현장 매뉴얼입니다.

- 오늘의 근무 일과 (평일 · 토요일 · 일·공휴일)
- 업무별 처리 방법, 인수인계 확인, 긴급상황 대응
- 보안대원(경비원) 업무 범위 (공동주택관리법 시행령 제69조의2)
